# **App Name**: FormFlow Pro

## Core Features:

- Step Form Creation: Build a multi-step form to capture user data for agreements and applications.
- Unique Tracking ID: Generate a unique tracking ID upon form submission to help users monitor their application status.
- Admin Action Panel: Create an admin interface to view submissions, details, and perform actions like changing the status (Submitted, In Progress, Completed, Rejected, Deleted).
- Status Updates: Implement status transitions.
- Automated Email Notifications: Send automatic thank you email messages upon form submission, along with a PDF attachment containing the submitted data. An LLM tool creates the message's custom thank you content, and the PDF formatting.
- PDF Report Generation: Convert the step form submission data to PDF.
- Data Storage: Use Firestore to save all forms so that they can be modified later by the administrator.

## Style Guidelines:

- Primary color: A calming, professional blue (#4A8FE7) to inspire confidence and trust.
- Background color: A soft, desaturated light gray (#F0F4F8) to ensure comfortable readability.
- Accent color: A vibrant purple (#A663CC) to draw attention to key actions and interactive elements.
- Body font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look, chosen for body text to ensure readability and a professional tone.
- Headline font: 'Space Grotesk', a proportional sans-serif with a computerized, techy, scientific feel; chosen for its professional style and readability
- Use clean, simple icons to represent each step in the form and each admin action.
- A clean, step-by-step form layout to reduce cognitive overload. Prioritize readability with ample whitespace and clear section headings.
